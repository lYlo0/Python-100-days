## Roadmap

| Stage | Days | Theme | Focus |
| ----- | ---- | ----- | ----- |
| 1 | 1–15 | Getting back into shape | Syntax, functions, containers, exceptions, small command-line tools |
| 2 | 16–30 | Engineering fundamentals | File I/O, modules, object-oriented programming, the standard library, unit testing |
| 3 | 31–50 | Web scraping | `requests`, HTML parsing, pagination, saving to CSV / SQLite |
| 4 | 51–70 | Data analysis | NumPy, pandas, matplotlib, analyzing the data scraped in stage 3 |
| 5 | 71–85 | Games & interfaces | pygame or Streamlit |
| 6 | 86–100 | Capstone projects | Chain scraping + analysis + presentation into complete projects, with tests and docs |

## Repository Layout

```text
days/       One folder per day: days/dayNNN-<slug>/ with main.py and README.md
projects/   Larger end-of-stage projects
notes/      Gotchas, lessons learned and 10-day retrospectives
scripts/    Helper tools (e.g. new_day.py to scaffold a new day)
```

Start a new day with:

```bash
python scripts/new_day.py 2 "file-organizer" --topic "Batch-organize files"
```

## Rules

1. **60–90 minutes a day.** Small and consistent beats long and occasional.
2. **Write it by hand first, then ask AI for a review.** AI is a reviewer, not the author.
3. **Be honest about gaps.** A missed day is marked ⏸️, never backfilled or hidden.
4. **Retrospective every 10 days.** Write it in `notes/` (e.g. `notes/retro-day010.md`).
