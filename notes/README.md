# Notes

Gotchas, lessons learned and retrospectives that are worth keeping beyond a single day.

## Stage plans

Each stage gets a day-by-day plan written when that stage starts, named `plan-stageN.md`:

- [Stage 1: Getting back into shape (Day 1–15)](plan-stage1.md)

## Gotcha notes

One file per topic, e.g. `notes/encoding.md` or `notes/requests-timeouts.md`. Each entry follows
the same shape as the daily README:

```markdown
## Short title (Day NNN)

- **Symptom:** what went wrong and what the error looked like
- **Cause:** why it happened
- **Fix:** what solved it, and how to avoid it next time
```

## Retrospectives

Every 10 days, write `notes/retro-dayNNN.md` (e.g. `retro-day010.md`) covering:

- What got done, and what was skipped or paused (and why)
- What was harder than expected
- What to change for the next 10 days
