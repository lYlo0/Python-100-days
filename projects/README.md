# Projects

End-of-stage projects that are bigger than a single day's script.

Each project lives in its own folder, e.g. `projects/job-market-dashboard/`, and should include:

- `README.md`: what it does, how to run it, which days it builds on, and a screenshot or GIF
- Source code organized into modules (not one giant script)
- Tests under a `tests/` folder (from stage 2 onward)
- A note on where its data comes from. Raw scraped data is **not** committed (see `.gitignore`)

The best 2–3 projects get featured in the root README.
